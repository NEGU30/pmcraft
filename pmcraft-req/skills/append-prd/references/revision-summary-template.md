## 未纳入建议决策条目

「未纳入本次修订的建议」非空时，每条建议追加一条决策记录（status `待确认`），使用以下 JSON 模板（写入 `pmcraft/temp/` 后经 `pmcraft-req:log-decisions` 传入：调用参数 `source` 取 `append-prd`，条目内 `source` 字段按模板固定 `未纳入建议`）：

```json
{
  "title": "未纳入建议：{建议一句话摘要}",
  "source": "未纳入建议",
  "status": "待确认",
  "background": "变更分析/用户确认阶段提出的建议，未纳入本次增量修订（版本 {版本号}，E{新编号}）。",
  "options": [
    "纳入后续迭代",
    "保持不纳入（人工复核后决定）"
  ],
  "decision": "待确认：{建议完整描述}",
  "reason": "本次修订范围外，记录在案供后续迭代评估。",
  "cost": "不处理该建议可能导致需求遗漏或重复提出。",
  "assumptions": [],
  "links": "{修订版 PRD 文件名}（E{新编号}）",
  "trigger_condition": null,
  "superseded_by": null
}
```

**填充规则**：每条建议一条条目；`source` 字段固定 `未纳入建议`；`status` 固定 `待确认`；`links` 指向修订版 PRD 文件名（E{新编号}）。**建议为空时禁止产生条目。**
