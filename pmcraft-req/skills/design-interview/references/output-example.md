# 访谈提纲：[用户流失]

**访谈人**：李四<1002>
**日期**：2026-06-04
**核心目标**：了解用户为什么不再使用我们的比价产品
**预计时长**：30 分钟（共 4 个核心问题）

**目标用户**：近 3 个月未回流的比价用户，曾使用至少 2 次
**招募方式**：系统筛出后电话邀请
**样本量**：8 人
**激励方式**：50 元红包

---

## 问题清单

### 开场（破冰）
1. 你今天怎么过来的？路上堵吗？
   意图：建立对话感

### 热身（进入回忆）
2. 你平时买大件家电一般会怎么挑？
   意图：了解比价习惯，不预设他用过我们产品
   - 如果 说"去京东看" → 追问：还去过哪？为什么先选京东？
   - 如果 说"朋友推荐" → 追问：你自己做过比较吗？
   - 如果 说"等打折" → 追问：你关注什么决定下手？

### 核心（逐层深入）
3. 你最近一次用我们产品是什么时候？当时在做什么？
   意图：了解使用频次和具体场景
   - 如果 说"上周" → 追问：过程顺利吗？
   - 如果 说"记不清" → 追问：当时想解决什么问题？
   - 如果 说"没用过" → 追问：你现在怎么比价的？

4. 当时比价过程中，大概花了多长时间？
   意图：侧面了解使用成本，避免直接问"有没有麻烦"
   - 如果 说"半小时以上" → 追问：最花时间的是哪一步？
   - 如果 说"很快" → 追问：你用了什么工具？
   - 如果 说"不记得" → 追问：挑到满意的一般看几个商品？

### 敏感话题（绕一下）
5. 有的人看重价格，有的人看重平台靠谱——你在选择比价工具时主要看什么？
   意图：了解决策维度，不直问"为什么不用我们"
   - 如果 说"价格" → 追问：你为了比价一般花多少时间？
   - 如果 说"靠谱" → 追问：你怎么判断一个平台可不可靠？

### 收尾（开放展望）
6. 如果你可以设计一个理想的比价工具，它会是什么样？
   意图：了解期望，有时最精彩的内容在这里
   - 如果 说了具体功能 → 追问：如果只能选一个，你选哪个？
   - 如果 说"想不出来" → 追问：现在比价最让你不舒服的是什么？

## 现场控场指引

| 场景 | 应对 |
|:---|:---|
| 用户说"不知道" | "没关系，那你当时在页面上看到了什么？"（退回 L1） |
| 用户跑题 | 先听，等停顿后拉回："你刚才说的有意思，我记下了。回到刚才的问题…" |
| 用户回答太简短 | 具体化追问："能举个具体的例子吗？" |
| 用户夸奖我们（奉承陷阱） | 不急着信，追问行为："那你上次用有遇到什么不顺的吗？" |
| 用户说"挺好的，就是…" | "就是"后面才是真话，追问："这个对你来说有多重要？" |
| 用户说自己的方案 | 深挖："你是怎么想到这个方法的？花了多少精力？" |
