# 问卷分析路径方法论

## 适用数据类型

- 问卷调查结果（含封闭题和开放题）
- NPS / CSAT 等满意度调研数据

## 分析约束

以下三条是问卷分析中必须遵守的纪律：

1. **禁止只报均值不报分布**：一项 3.5 的平均满意度，可能是所有人都不咸不淡（集中在 3），也可能是半数极满意半数极不满（双峰分布 1+5）。分布形态比均值更有信息量。
2. **禁止对 Likert 数据做均值比较**：Likert 量表是顺序数据（ordinal），"非常同意"和"同意"之间的距离不等于"同意"和"一般"之间的距离。对顺序数据应报告中位数和分布比例，而非均值和标准差。
3. **禁止从相关推断因果**：交叉分析中发现的群体差异（如"高频用户满意度更低"）是相关性发现，不是因果结论。报告时应标注"指示性差异"或"统计显著差异"，并提供可能的因果方向供 PM 判断。

## 分析序列

### Phase 0：合约解析（条件执行）

**触发条件**：PM 提供了调研计划时执行。若未提供，跳过本阶段，标注"未提供调研计划"。

从调研计划中抽取分析合约并输出为执行清单：

| 抽取项 | 来源章节 | 用途 |
|:---|:---|:---|
| 假设清单 | 1.3 核心假设 | 每条假设必须在报告的假设验证汇总中给出"通过/推翻/部分验证" |
| 分层对比要求 | 1.9 数据分析思路 | 生成交叉表，不可退化为零星个案引用 |
| 数据偏差规则 | 1.9 偏差标注 | 分析前按规则标记样本（如"<1年排除对比题"） |
| 置信边界声明 | 1.4 样本量+性质 | 在报告开头明确统计方法边界 |

执行清单在分析完成后（Phase 7）逐项对账。

## 阶段一：机械核查

阶段一产出结构化事实表，不做任何解释或推断。这些表同时作为报告附录的素材。

### Phase 1: 数据概览

输出数据基本信息：

| 维度 | 内容 |
|:---|:---|
| 样本量 | N = {X}，回收率 = {Y}% |
| 人群分布 | 关键人口统计字段的分布（年龄/角色/使用频率等，按问卷实际有的字段） |
| 答题时长 | 均值、标准差、异常样本标记（< 均值-2σ 或 > 均值+2σ） |
| 置信度 | 如有置信区间要求则标注（如 95%CI ± X%），如无则标注"未指定" |
| 代表性声明 | 样本是否能代表目标人群？偏差方向？ |

### Phase 2: 逐题频次分布表

逐道封闭题做描述统计，**每题必出表**。每道题至少报告：

**量表题（Likert / 满意度 / 频率）：**
- 频次分布表（每个选项的 N 和 %）
- 分布形态判断：单峰（集中在哪个区间）/ 双峰（两个极端的群）/ 偏态（倾向哪端）/ 均匀
- 中位数（不报均值！）

**单选题：**
- 每个选项的 N 和 %
- Top 3 选项

**多选题：**
- 每个选项的被选频次和占总人数的 %
- 常见组合（同时选 A+B 的人数）

**排序题：**
- 每个选项的平均排名 / Top 1 比例

### Phase 3: 交叉表

按人群分段看差异。**优先执行调研计划 Phase 0 承诺的分层对比维度**（若提供了调研计划）。

**纪律：**
- 每个交叉分析标注是"统计显著"还是仅"指示性差异"。小样本（N<30）下不做显著性推断。
- 每项差异标注可能的因果方向（不是结论，而是供 PM 验证的假设）。
- 如果某一细分群体样本量 < 10，不单独交叉分析，合并到"其他"或跳过。

### Phase 4: 异常标记

基于阶段一已产出的结构化数据，标记以下异常：

| 检查项 | 方法 | 处理 |
|:---|:---|:---|
| 内部回答矛盾 | 同一受访者在逻辑互斥的题目上给出矛盾回答 | 排入数据质量评估 |
| 全量/0人声明验证 | 对阶段一中出现的每个"全员/0人"类数字，逐条在原始数据中检索反例 | 修正相关结论中的数字 |
| 注意力检测结果 | 统计通过/未通过人数 | 排入数据质量评估 |
| 答题时长异常 | 标记用时在均值 ±2 标准差之外的样本 | 排入数据质量评估，讨论是否影响结论 |

## 阶段二：模式识别

阶段二基于阶段一已验证的事实表做推理。**禁止重新计数——所有数字引用阶段一的产出。**

### Phase 5: 开放题编码

对开放题回答做简化版标引-聚类-命名（同访谈分析路径 Phase 2-4）。
因开放题回答通常较短（1-3 句话），标引和聚类可以合并为一轮——直接基于回答内容分组主题。
每条开放题标注回答者的关键特征（如角色/使用频率，从封闭题中提取），用于 Phase 6 的综合洞察。

⚡ **批判性停顿：开放题编码 → 综合洞察**

在进入综合洞察前，对开放题编码执行以下反思。**发现问题后回退修正，不修正不允许进入下一阶段。**

| 维度 | 问题 |
|:---|:---|
| 确认偏误 | ① 开放题编码时是否被少数表达清晰、情绪强烈的回答带偏了？② 封闭题的数据结论是否暗示了阅读开放题时的方向？ |
| 替代解释 | ① 开放题回答者与封闭题是同一批人——打字长度反映投入度吗？短回答是否被忽略了？② 当开放题主题与封闭题数据矛盾时，我是否倾向于选择数据质量更高的一方而忽视了矛盾本身的价值？ |
| 宣称强度 | ① 一个主题在开放题中出现了 N 次，这个 N 是否足以称为"模式"？（≤2 次 → 个案，标注即可）② 开放题中只有 1 人提到的观点是否已被标注为"个案"而非纳入了综合洞察？ |

### Phase 6: 综合洞察

封闭题发现 + 开放题主题合并为综合洞察。

| 证据类型 | 来源 | 标注 |
|:---|:---|:---|
| `[定量]` | 封闭题的频次分布、交叉差异 | 标注样本量和统计指示性 |
| `[定性]` | 开放题的主题编码 | 标注提及人数 |
| `[交叉验证]` | 同一主题在封闭题和开放题中均有支撑 | 可信度升级为"高" |

⚡ **批判性停顿：综合洞察内部（模式 → 推断）**

在确认洞察前执行以下反思。**发现问题后回退修正。**

| 维度 | 问题 |
|:---|:---|
| 确认偏误 | ① 是否只关注了"统计显著"的差异，忽略了"不显著但方向一致"的信号？② 是否因为某组样本量小就直接跳过了该组的模式？ |
| 替代解释 | ① 交叉分析的群体差异是相关性还是因果？是否存在第三变量？② Likert 数据的中位数差异真的有意义，还是问卷措辞导致的？ |
| 宣称强度 | ① 封闭题和开放题的一致性程度是否如实反映在信任度标注中？② 如果一致性低，我是否标注了"待验证"而非强行统一？ |

### Phase 7: 合约对账

**触发条件**：Phase 0 已执行（即 PM 提供了调研计划）。

逐项检查 Phase 0 抽取的执行清单，标注完成状态：

| 状态 | 含义 |
|:---|:---|
| ✅ 已完成 | 该项分析已在上述阶段中完整执行 |
| ⏭️ 跳过 | 该项分析因数据条件不满足而跳过（附理由） |
| ⚠️ 无法执行 | 该项分析因数据格式/样本等限制无法执行（附原因） |

对账结果作为质量声明中"模块完整性"维度的输入。

⚡ **批判性停顿：综合洞察 → 决策输出**

在进入最终产出前，对综合洞察执行以下反思。**发现问题后回退修正，不修正不允许进入下一步。**

| 维度 | 问题 |
|:---|:---|
| 确认偏误 | ① 我是否倾向于给出"继续做/优化"的建议，而避开了"停止/搁置"的建议？② 如果换一种人群分层方式，会不会得出不同结论？ |
| 替代解释 | ① 问卷的选项措辞是否可能引导了回答方向？如果措辞不同，结果会不同吗？② 答题时长异常的样本被排除了还是保留了？如果排除，结论是否改变？ |
| 宣称强度 | ① 每条综合洞察是否标注了证据类型和强度？② 小样本（n<30）下的结论是否已标注"指示性差异"而非结论性陈述？③ 当给出"推翻假设"类宣称时，证据是否充分（多题交叉验证+定性支撑）？ |

## 条件产出物门禁

条件产出物的通过条件和降级规则统一维护在 `quality-gates.md`（与本文档同目录，门禁 B 判定标准）。本路径仅关注特定于问卷数据的降级形态：

| 产出物 | 不通过时的降级输出 |
|:---|:---|
| 用户画像 | 人口统计特征摘要 — 仅描述样本的客观分布（年龄段/角色/使用频率等），不添加任何蓝色推断；标题明确标注 `[非用户画像，为样本描述]` |
| 痛点排序 | 正常生成（封闭题提供满意度/频率数据，开放题提供具体问题描述，两者组合即构成痛点排序） |
| 机会点陈述 | 待验证假设（变通方案信息不足时） |

## 统计表格模板

### 频次分布表

```markdown
**Q{N}. {题目标题}** （N = {X}）

| 选项 | 人数 | 占比 |
|:---|:---:|:---:|
| {选项1} | {N1} | {P1}% |
| {选项2} | {N2} | {P2}% |
| ... | ... | ... |

分布形态：{单峰/双峰/偏态/均匀}。中位数：{M}。
```

### 交叉分析表

```markdown
**交叉分析：{分组变量} × {目标变量}**

| 分组 | N | {指标1} | {指标2} | 差异显著性 |
|:---|:---:|:---:|:---:|:---:|
| {群体A} | {NA} | {值} | {值} | — |
| {群体B} | {NB} | {值} | {值} | {指示性/显著} |

解读：{一句话，标注相关≠因果}
```
