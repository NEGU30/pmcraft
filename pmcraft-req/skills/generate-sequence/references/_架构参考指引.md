# 系统架构参考文件 — 使用指引

> 此文件为指引占位文件，`generate-sequence` 技能会自动跳过（以下划线 `_` 开头），不会将其作为架构参考使用。

## 两种使用方式

### 方式一：放技能目录（随插件分发，临时参考）

将架构参考文件放入本技能 `references/` 目录（即当前所在目录），技能运行时自动扫描。

> ⚠️ **注意**：插件升级重装会重建该目录，放这里的文件会被清空。仅适合临时参考。

### 方式二：放项目目录（推荐，长期资料）

将架构参考文件放在项目目录下（如项目 `pmcraft/` 目录或与 PRD 同域目录），运行技能时在询问环节提供文件路径即可。

> 长期资料推荐此方式——不受插件升级影响，且天然跟随项目版本管理。

## 文件格式建议

```markdown
# 系统架构参考

## 系统清单
| 系统名称 | 归属 | 职责 | 接口类型 | 备注 |
|:---|:---|:---|:---|:---|
| 账号中心 | 本项目组 | 用户注册、登录、手机绑定、密码管理 | HTTP API | home 子系统 |
| 短信网关 | 非本项目组 | 短信验证码下发与校验 | RPC | 第三方：阿里云短信 |
| 前端(Web) | 本项目组 | 用户交互界面 | — | React SPA |
```

## 文件粒度

建议一个业务域一份，该域下所有 PRD 共用。首次使用前准备，后期有变化时直接更新。

## 注意事项

- 架构参考文件中的系统名会被原样使用，请保持命名准确一致
- 若 PRD 文本明确区分了同一架构系统的不同交互边界，`generate-sequence` 会自动拆分 participant 并以蓝色标注
- 文件名不限，`.md` 格式即可；放入技能目录时请勿以下划线 `_` 开头（会被过滤），放项目目录则无此限制
