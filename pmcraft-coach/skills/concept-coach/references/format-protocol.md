# 压缩细则（"简短点"/"压成三句"）

> 触发：用户说 "简短点" / "压成三句" / "一句给我" / "跟老板汇报用" / "我要去开会了" 等。

## 两种格式

### 压成三句（对应 eli-brief，可贴给老板/客户/董事会）

恰好 3 句，每句 ≤20 词，聪明忙碌的读者，不幼稚化：

```
[它是什么——一句类比]
[为什么值得关注——业务影响]
[需要拍板/留意的事]
```

### 一句给我（对应 eli-tldr，自己记）

恰好 1 句 ≤20 字（比 eli 的 3 条更简——用户说"一句"就是要最少的）：

```
[类比一句：它像 X，因为 Y]
```

> 若用户说"压成三句"则用三句格式；说"一句给我"则用一句格式。没说清 → 默认三句。

## 规则

1. **结构固定，无前后缀散文**——不要"好的！让我想想…"
2. 压缩不是删减：宁可少给事实，不丢准确性（对齐"准确优先"）
3. 装不下 → 明说"这个概念一句讲不全，最少三句"——不硬压
4. 输出前过门禁检查。
