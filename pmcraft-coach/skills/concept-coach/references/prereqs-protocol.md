# 学习路径细则（"学之前要先懂啥"）

> 触发：用户说 "学它之前要先懂啥" / "给个学习路径" / "从哪开始" / "我想系统学下 X" 等。

## 格式

```markdown
## 学 [概念] 之前，你需要先懂：
1. **[前置概念]** — [一句白话。约需：X 天/小时]
2. **[前置概念]** — [一句白话。约需：X 天/小时]
3. **[前置概念]** — [一句白话。约需：X 天/小时]

## 然后：[概念本身]
[一句话总结]

## 学完后你能做：
- [具体能力 1]
- [具体能力 2]

## 现在就开始 →
[可执行的第一步：读什么/问什么/拿什么练手]
```

## 规则

1. **前置 ≤3 个**（PM 学习时间有限，超过 3 个就链式处理：先学 A 再回头问）
2. **拒绝空话**："掌握基础知识"不算前置——必须具体到能查能问的东西
3. **时间估计诚实**：宁多勿少，标注"这个要几天，别急"
4. **查已学**：先查用户级 `_concepts.md`，用户学过的前置标"（你已学过，跳过）"
5. **Start here 必须可执行**：具体到读哪篇/搜什么/问哪句，不是"去学习吧"
6. 输出前过门禁检查。
