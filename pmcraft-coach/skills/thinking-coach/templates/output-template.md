## 锚点式自我评分参考

### 思考深度（本场 sparring）
| 分数 | 锚点 |
|:---|:---|
| 1 | "我只是回答了一些常规问题" |
| 2 | "有一些思考，但都在舒适区内" |
| 3 | "被一两个问题问住了，想了很久" |
| 4 | "发现了自己长期忽视的盲区" |
| 5 | "颠覆了之前的某个核心假设，并且找到了验证方法" |

### 收获感（本场 sparring）
| 分数 | 锚点 |
|:---|:---|
| 1 | "没什么新启发" |
| 2 | "有些触动，但说不清是什么" |
| 3 | "有几个点让我印象深刻" |
| 4 | "对一个问题有了全新的理解" |
| 5 | "这次交流可能改变我接下来做事的思路" |
