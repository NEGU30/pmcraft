## 案例 1：丰田按灯系统（制造业）

### 背景
丰田生产线上的工人发现任何质量问题时，有权拉下"按灯绳"（Andon Cord）让整条产线停下来。在传统制造业逻辑中，"停线 = 损失产能 = 不可接受"。但丰田反其道而行之。

### 训练重点
- 产品化：标准化（SOP）/ 自动化 / 规模化（三列并行，非递进）
- 第一性原理：为什么"停线"这个看似低效的行为，本质上是最高效的？

### 引导问题
1. "如果你是一线工人，在什么情况下你会真的拉绳？什么情况下你会犹豫？"
2. "这个系统可以被滥用的方式有哪些？丰田应该是怎么防止的？"
3. "互联网公司的'on-call 告警升级机制'和按灯系统，本质上是同一件事吗？"
4. "如果你的团队现在有一个'按灯'权力——任何人发现质量问题可以叫停发布——你会设计什么规则？"

### 参考思考维度
- 发现问题的成本 vs 修复问题的成本的时间分布
- 赋权（empowerment）的前提是 SOP 明确
- 标准化不是"固化"，而是"让异常可以被识别"


## 案例 2：SpaceX / 马斯克五步工作法（制造业）

### 背景
SpaceX 通过第一性原理将火箭发射成本降低了 90%+。马斯克的五步工作法：① 质疑需求（Make requirements less dumb）→ ② 删除（Delete）→ ③ 简化/优化（Simplify/Optimize）→ ④ 加速（Accelerate）→ ⑤ 自动化（Automate）。

### 训练重点
- 第一性原理：从原材料成本倒推
- 产品化：注意自动化在最后一步——顺序本身是洞察

### 引导问题
1. "马斯克把'自动化'放在最后一步。大多数公司从哪步开始？为什么顺序错了？"
2. "一个火箭的原材料成本只有最终售价的 ~2%。你的产品里，什么成本其实是'惯例'而不是'物理'？"
3. "你最近有没有'自动化了一个应该先被删除的东西'的经历？"
4. "五步里最难做到的是哪一步？为什么？"

### 参考思考维度
- 惯例 vs 物理约束的区分
- 先做减法再做自动化——不然自动化的是浪费
- 质疑需求不是说"需求错了"，而是"这个需求是怎么来的"


## 案例 3：亚马逊逆向工作法（互联网）

### 背景
亚马逊产品团队在启动任何新项目前，必须先写一份"内部新闻稿"（Press Release）和 FAQ——假设产品已经发布，用面向客户的语气描述它解决了什么问题、为什么值得关注。新闻稿写完才开始做。

### 训练重点
- 解决问题：从用户看到的结果反推，而非从技术能力正推
- 批判性思维：新闻稿迫使你直面"这到底对用户有什么价值"

### 引导问题
1. "你现在做的功能，如果让你写一份'假新闻稿'，标题会是什么？读者读到第三段会继续吗？"
2. "新闻稿写完后发现说服不了自己——这个产品还该做吗？"
3. "和丰田按灯系统一样，这个方法把'发现问题'的时间点大幅前置了。你的团队里有没有类似的'前置检查点'？"
4. "逆向工作法在 AI 时代会不会失效？当竞争对手可以 3 天 copy 你的产品时，'先写新闻稿'还有意义吗？"

### 参考思考维度
- 从结果反推 vs 从能力正推
- "写不出来的东西 = 没想清楚"
- 面向用户的语言是第一道产品过滤器


## 案例 4：7-11 先进先出补货系统（零售/供应链）

### 背景
日本 7-11 创始人铃木敏文把"单品管理"做到极致——每家门店根据当天的天气、周边活动、时段来动态调整货架，一天补货多次，而不是"每周大补一次"。信息流驱动物流，而非反过来。

### 训练重点
- 产品化：标准化（每家店怎么知道该补什么？）/ 自动化（POS数据实时驱动）/ 规模化（全国几万家店各自不同）
- 解决问题：真正的用户不是"买东西的人"，而是"这家店面前的这个人在这个时刻的需求"

### 引导问题
1. "为什么中国便利店至今没做到 7-11 级别的单品管理？是技术问题还是组织问题？"
2. "7-11 的加盟店老板每天花 2 小时看数据决定明天的货架——这个 SOP 的核心瓶颈在哪？"
3. "你觉得 7-11 的补货系统先做对了第一步（标准化）还是第三步（规模化）才能成功？"
4. "类比到 SaaS：你的产品能不能做到'不同客户看到的功能/内容不同'，而非一刀切？"

### 参考思考维度
- 信息流驱动物流 > 物流驱动信息流
- 规模化的前提是标准化做透，自动化的前提是标准化的判断逻辑可被规则化
- "单品管理"的本质是"降低决策粒度"


## 案例 5：二战飞机弹孔 / 幸存者偏差（跨行业/统计）

### 背景
二战期间，盟军统计返航飞机的弹孔分布，发现机翼弹孔最多，准备加固机翼。亚伯拉罕·沃尔德（Abraham Wald）指出：应该加固弹孔最少的部位——引擎。因为引擎中弹的飞机没飞回来。

### 训练重点
- 批判性思维：你看到的数据排除了什么？
- 第一性原理：从"飞机要飞回来"这个目标倒推，而非从弹孔分布正推

### 引导问题
1. "你的产品数据里，什么'返航飞机'在告诉你错误结论？你正在看的数据排除了什么？"
2. "用户流失数据是'弹孔图'还是'残骸图'？"
3. "你最近做过的哪次 AB 测试，可能犯了'只统计返航飞机'的错误？"
4. "在你所在的组织里，有没有'沉默的失败'——那些没被记录的错误决策？怎么让它们可见？"

### 参考思考维度
- 缺失数据比现有数据更重要
- "成功学"的陷阱：只看活下来的公司，不看死掉的
- NPS/满意度调查只看"愿意回复的人"——那沉默的人呢？


## 案例 6：滴滴司机车内卖咖啡（互联网平台/社会民生）

### 背景
广东网约车司机在车内卖咖啡给乘客，被媒体曝光后平台以"不建议"回应。司机本质诉求是增收，平台面临安全与边界问题。

### 训练重点
- 解决问题："这不是卖咖啡的问题，而是司机增收渠道缺失的问题"
- 批判性思维：平台"不建议"背后的真实权衡是什么？

### 引导问题
1. "司机卖咖啡，对乘客、对司机、对平台各有什么影响？谁受益谁受损？"
2. "假设你是滴滴的 PM，你会如何回应？选择① 禁止（安全优先）② 引导（设立'司机服务'模块）③ 忽略——每个选项的代价是什么？"
3. "这个案例里，平台'不建议'的三字回应是否恰当？如果换成'我们看到司机有增收需求，正在探索合规途径'又有什么问题？"
4. "你能想到哪些平台边界被用户行为'撑开'的类似案例？平台该收缩还是该吸收？"

### 参考思考维度
- 区分"表面行为（卖咖啡）"与"真实需求（增收）"
- 平台边界的判断框架：安全/体验/收入的三角权衡
- "不建议"是典型的非决策——不求有功但求无过


## 案例 7：海底捞等位服务（服务业/餐饮）

### 背景
海底捞把"等位"这个几乎所有餐厅都在逃避的用户痛点，做成了招牌体验——美甲、擦鞋、水果、棋牌。不是"减少等位时间"，而是"让等位不再痛苦"。

### 训练重点
- 解决问题：用"不是…而是…"重构——"这不是减少等待时长的问题，而是降低等待感知痛苦的问题"
- 产品化：标准化（每个服务员知道等位区该做什么）/ 自动化（排号系统）/ 规模化（跨城市复制）

### 引导问题
1. "你的产品里，有什么'等位区'是你一直在逃避的？如果把它变成招牌体验会怎样？"
2. "海底捞等位服务的可复制性在哪？为什么其他火锅店做不到？是意愿问题还是能力问题？"
3. "标准化服务业——美甲师的招聘和培训 SOP 长什么样？如果无法标准化，海底捞为什么还要做？"
4. "反演：海底捞的等位服务，在什么情况下会变成负担而非加分项？"

### 参考思考维度
- 消除痛点 vs 转化痛点
- 服务产品化的关键是可复制 SOP
- "超预期"的体验本身需要被标准化才能规模化


## 案例 8：强生 Tylenol 召回危机（医疗/公共）

### 背景
1982 年，芝加哥地区 7 人因服用被氰化物污染的泰诺（Tylenol）死亡。强生立即召回全美 3100 万瓶产品（损失 1 亿美元），并推出三重防篡改包装。此举建立了全球药品安全包装标准。

### 训练重点
- 批判性思维：短期损失 1 亿 vs 品牌死亡——决策的真实约束是什么？
- 产品化：从危机应对到行业 SOP

### 引导问题
1. "强生召回全部产品的决策如果是你，你会在什么情况下做同样的决定？什么情况下做不同的决定？"
2. "产品出问题时，先保护用户还是先保护公司——这两个选择在什么时间尺度上会趋同？在什么时候会分化？"
3. "防篡改包装变成行业标准后，所有公司的起点又一样了——从产品化的角度，Tylenol 的竞争优势就此消失了吗？"
4. "你负责的产品里，有没有什么风险你一直知道但拖延了没处理？如果是 Tylenol 事件的主角，你会后悔哪个拖延？"

### 参考思考维度
- 短期利益 vs 长期信任
- 危机驱动的标准化（防篡改包装）如何变成行业基线
- "底线规则"的确立往往来自一次重大代价
