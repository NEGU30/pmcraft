# 扩展示例

## 正例：探索模式选热点 → 完整材料包

**输入**：说「思维训练」或「sparring」→ 选 2（来个热点） → 选中某条热点

**预期执行路径**：
1. AI 按前置检查表（📡 行）调用 hot-topic-collect workflow（传入当前日期），做四领域×两档（本周/本月）搜索并过可聊性筛子，展示热点列表（简版：标题 + 一句话摘要 + 分类标签）。
2. PM 选中一条热点（如"拼多多 Temu 全球化遇阻"）。
3. AI 按前置检查表（📋 行）调用 material-pack workflow 生成该话题的完整材料包——时间线、一组数据、各方怎么说（含反面声音）、可聊方向、参考来源（≥2 条 URL）。
4. AI 输出"材料都在上面了。你先看，有想聊的方向随时说，或者我来问也行——节奏你来定。"
5. PM 说"够了，来吧" → 进入步骤 0。
6. 步骤 0 及后续流程同第一条正例。

## 正例：用户带模糊话题 → 完整材料包

**输入**：
```
说「思维训练 自动驾驶」
```

**预期执行路径**：
1. 识别到话题参数，但 ≤5 字且无具体事件 → 判定为模糊话题。
2. AI 按完整材料包结构收集材料（≤3 次抓取）：时间线、数据、各方怎么说、可聊方向、参考来源。
3. AI 输出材料包 + "自动驾驶这个范围有点大。你先看材料，看看对哪个方向有感觉。"
4. PM 消化材料后说"我对保险那块感兴趣" → AI 以保险视角为切入点，进入步骤 0。
5. 步骤 0 及后续流程同第一条正例。
