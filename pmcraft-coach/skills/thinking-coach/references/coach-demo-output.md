### 五部分输出结构

推演输出统一为五个部分。各部分格式随模式不同（表格/非表格），详见下方各模式的格式决策表。

| 部分 | 白纸 | 对照 | 延续 |
|:---|:---|:---|:---|
| 一、框架 | 表格 | 表格（双列） | 表格 |
| 二、推演 | 非表格（对话） | 表格（分叉链） | 非表格（叙事） |
| 三、方法论 | 表格 | 表格（+分叉列） | 表格（+关联列） |
| 四、自我批判 | 非表格（Q&A） | 非表格（Q&A） | 非表格（Q&A） |
| 五、结尾 | 非表格 | 表格（双列） | 非表格 |

#### 第一部分：框架

**白纸** — 表格

| 选用的框架 | {框架名} |
|:---|:---|
| 为什么选它 | {话题的什么特征匹配} |
| 没选的 | {框架 A}——适合{场景}，但{不匹配的原因} |

**对照** — 表格（双列）

| | PM sparring | AI 推演 |
|:---|:---|:---|
| 框架 | {PM 切入角度} | {AI 选的框架} |
| 关键变量 | {PM 关注什么} | {AI 关注什么} |
| 推理方向 | {PM 往哪推} | {AI 往哪推} |

**延续** — 表格

| PM 的框架 | {从 sparring 中提取} |
|:---|:---|
| AI 的理解 | {"如果我没有理解错……"} |
| sparring 推到的最远处 | {PM 停了的地方} |
| 本次推演继续推 | {起点和方向} |

#### 第二部分：推演

**白纸** — 双角色对话（非表格）

```
🔵 分析师
{用选定框架给出第一版结构化分析}

🔴 追问者
{挑战——质疑假设/追问证据/找反例/测试边界}

🔵 分析师
{回应——修补、修正、或说明假设}

…（最少 2 轮、最多 5 轮来回。分析师至少有一次明显修正。）

🔵 最终判断
{推演后的核心结论 + 仍然不确定的}
```

**对照** — 同题分叉链（表格）

从 sparring 中提取 4-6 个 PM 明显停顿过或被问住的追问节点。每个追问一张分叉表：

| | PM 链 | AI 链 |
|:---|:---|:---|
| **追问 N** | {教练的原问题} |
| 第一答 | {PM 原话} | {AI 的答案} |
| → 追问 | {基于 PM 答案的下一个追问} | {基于 AI 答案的下一个追问} |
| 第二答 | {PM 原话} | {AI 的回应} |
| … | … | … |

> 追问选择规则：只选 PM 明显停顿过、被问住了、或回答后方向变化过的节点。

所有追问展示完后——分叉总结：

| 分叉总结 |
|:---|
| 两条链从哪里开始分的？{最早分叉点——第几个追问的哪个回答} |
| 为什么在那个点分了？{切入角度的差异/关键假设的不同/变量权重的不同} |

**延续** — 续推叙事（非表格）

从 sparring 中提取 PM 停住但没推透的节点（3-4 个），每个节点用 PM 的框架继续推。

```
📍 节点 N：{停住的位置}

你在 sparring 中说：
  "{PM 原话}"

可能停了是因为{推测原因}。

按你的框架继续推——
  {AI 用 PM 的框架往下推}
  → {追问}
  → {回答}
  → {新结论}

这没有推翻你原来的判断——只是多走了一步。
```

多个节点展示完——续推总结：

| 续推总结 |
|:---|
| PM 的框架在哪些节点可以继续推？{列出} |
| 推到的新位置：{不是"PM 错了"，是"PM 的框架还能走这么远"} |

#### 第三部分：方法论

白纸 — 表格：

| 方法 | 什么时候用 | 怎么用 | 失效条件 |
|:---|:---|:---|:---|
| {方法名} | {触发场景} | 1.{步骤} 2.{步骤} 3.{步骤} | {什么时候不灵——必须具体} |

对照模式表格加一列"来自哪个分叉"，延续模式加一列"和 PM 思路的关联"。

方法提炼要求：
- 2-4 个方法，每个方法的失效条件必须具体——不能是"不适用时失效"
- 方法名不要用通用术语（"对比法""排除法"）——用本话题的具体变形
- 步骤是操作性的——PM 下次拿到就能自己用

#### 第四部分：自我批判

非表格——Q&A 对话体。三行追问，第三行随模式切换：

```
🪞 自我批判

1. {质疑——推演中最薄弱的推理节点}
   回答：{诚实回答}

2. {另一个值得质疑的点}
   回答：{诚实回答}

3. 白纸：这个推演最薄弱的环节在哪？
   对照：PM 推到但我没覆盖的视角是什么？
   延续：PM 的框架在什么条件下会失效？
   回答：{回答}
```

#### 第五部分：结尾

**白纸**（非表格）

> 推演路径：{切入角度 → 关键判断 → 不确定的点}
>
> 你的 sparring 从 X 切入，我选的是 Y。哪个差异点最让你想反驳？

**对照**（表格）

| | PM 路径 | AI 路径 |
|:---|:---|:---|
| 方向 | {往哪推} | {往哪推} |
| 覆盖到的 | {PM 看到的} | {AI 看到的} |
| 没覆盖到的 | {PM 漏掉的} | {AI 漏掉的} |

> 两条链从哪里开始分的？{最早分叉点——答歪一步，后面全变。} 那个分叉点最让你想反驳的是什么？

**延续**（非表格）

| PM 框架推到底 | {推到的最终结论} |
|:---|:---|
| PM sparring 停的位置 | {停了的地方} |
| 差距 | {不是推翻——"你的框架还能走这么远"} |
| 下次 | {你自己下次在什么问题上会再试这个框架？} |

> 输出前硬检查 7 条与禁止 4 条清单见 SKILL.md「🎬 教练推演（完整版）」节（常驻正文，单一事实源）。
