**完整材料包模板**（适用于热点 / 用户自带模糊话题）：

```
📋 阅读材料：{话题标题}

━━━ 时间线 ━━━
（按时间顺序列出关键事件，纯事实，每条一行）
- YYYY.MM 事件一
- YYYY.MM 事件二
- …

━━━ 一组数据 ━━━
（关键数字：规模、增速、成本、对比数据等，纯事实）
- 数据项一：X
- 数据项二：Y
- …

━━━ 各方怎么说 ━━━
（至少 3 个不同立场的说法，纯引用/转述，不给判断。必须包含至少一个与主流叙事相反的立场。）
- 当事方 A："…"
- 当事方 B："…"
- 第三方/用户/分析师："…"
- （必须包含）反面声音："…"

━━━ 可聊的几个方向 ━━━
（只给开放性问题，不给答案）
- 方向一？
- 方向二？
- 方向三？

━━━ 参考来源 ━━━
- [来源标题](URL) — 一句话说明这是什么
- [来源标题](URL) — 一句话说明这是什么
```
