# 弹药库：感受型问题模板（heuristic-checklists）

> 用途：walkthrough Phase 9.2 生成任务清单时按旅程选配；Phase 9.4 按需追问时的追问弹药。
> 纪律：**只放感受型问题（问"你的第一反应/做了什么/感觉如何"），不放检查型（问"有没有 X"）**。
> 六维覆盖：可达性 / 反馈与状态 / 认知负担 / 错误恢复 / 情绪体验 / 系统一致性。
> 使用：按旅程环节（找入口/填表/提交/看结果/返回）从对应维度选 2-3 条，改写为产品语境。

## 一、六维感受型问题模板

### 1. 可达性（能不能找到）

| # | 问题模板 |
|---|---------|
| A1 | 你第一反应是去哪找{入口/功能}？一次就找到，还是找了一会儿？ |
| A2 | 你找{入口}时，第一眼看到的是什么？ |
| A3 | 如果 3 分钟还没找到{入口}，记下来——这本身就是重要发现（兜底） |
| A4 | 你试了哪几条路才找到{入口}？哪条路你觉得最自然？ |

### 2. 反馈与状态（我做的动作有没有回应）

| # | 问题模板 |
|---|---------|
| F1 | 点下{提交/查询}后，页面给了你什么反馈？那一刻你心里踏实吗？ |
| F2 | 等结果的时候，你在想什么？ |
| F3 | 结果出来那一刻，符合你的预期吗？差在哪？（落差问法） |
| F4 | 做完{动作}，你知道自己成功了吗？怎么知道的？ |
| F5 | 中间断了/失败了，页面有告诉你为什么吗？ |

### 3. 认知负担（好不好懂）

| # | 问题模板 |
|---|---------|
| C1 | 填{表单/信息}时，有没有哪个字段让你琢磨了一会儿？琢磨什么？ |
| C2 | 这个页面上的{术语/文案}，你一眼看懂了吗？哪句没看懂？ |
| C3 | 你知道自己现在在哪一步吗？下一步该干嘛，你清楚吗？ |
| C4 | 有没有哪个按钮，你看了但不确定它是干嘛的？ |

### 4. 错误恢复（点错了怎么办）

| # | 问题模板 |
|---|---------|
| E1 | 填错/点错了，你是怎么处理的？按你的习惯来 |
| E2 | 你想回到上一步的时候，是怎么做的？顺利吗？ |
| E3 | 如果一步走错，你觉得还能挽回吗？当时慌没慌？ |

### 5. 情绪体验（顺不顺心）

| # | 问题模板 |
|---|---------|
| M1 | 这个旅程里，哪个时刻让你最顺心/最别扭？ |
| M2 | 有没有哪个时刻让你犹豫了一下？犹豫什么？ |
| M3 | 走完这个旅程，你是松口气，还是有点烦？ |

### 6. 系统一致性（和惯用模式像不像）

| # | 问题模板 |
|---|---------|
| S1 | 有没有哪里和你平时用的其他{同类产品/网站}不一样，让你愣了一下？ |
| S2 | {某个交互}和你预期的习惯一样吗？差在哪？ |

## 二、偏离点库（可选探索方向，一次一个）

> 用法：每旅程选 1 个，套"如果你好奇，可以试试……看看会发生什么——把结果记下来"句式。

| 偏离点 | 暴露的问题面 | 优先级 |
|--------|-------------|--------|
| 刷新页面 | 状态丢失、结果是否保留 | 高（通用高危） |
| 浏览器后退 | 状态丢失、表单数据保留、死链 | 高（通用高危） |
| 返回首页再进入 | 入口一致性、状态保留 | 高（通用高危） |
| 填错数据（错格式/错账号） | 错误反馈、校验时机 | 中（业务特定） |
| 空输入直接提交 | 校验提示、禁用状态 | 中 |
| 快速连点 | 重复提交、防抖 | 中 |
| 多标签同时开 | 并发状态、登录态 | 低 |

## 三、结构件三件套（每次生成必带，不依赖选配）

| 结构件 | 写法模板 |
|--------|---------|
| ① 兜底 | "如果 {N} 分钟还没找到{入口}，记下来——这本身就是重要发现" |
| ② 落差问法 | "{动作}那一刻，符合你的预期吗？差在哪？" |
| ③ 记录钩子 | 偏离提示后缀："看看会发生什么——把结果记下来" |

## 四、选配原则

1. **按环节选**：找入口 → 可达性（A 族）；填表 → 认知负担（C 族）+ 错误恢复（E 族）；提交/等结果 → 反馈与状态（F 族）；收尾 → 情绪体验（M 族）
2. **每旅程 2-3 条**：1 条覆盖核心价值时刻（F 族优先），1 条覆盖高发摩擦环节（找入口 A 族 / 填表 C 族），1 条按产品风险选
3. **改写为产品语境**：模板是弹药不是死句，必须落到具体旅程（如 A1 → "你第一反应是去哪找迁移查询入口？"）
4. **人设相关优先项**：人设（如"担心账号安全"）与某环节相关时（填枪号），优先选该环节问题并自然带出人设语境
