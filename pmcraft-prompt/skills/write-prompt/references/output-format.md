# 输出格式规范

本文档定义了 `prompt-writer` 生成提示词时的标准输出结构。每次输出必须包含以下 4 个部分。

---

## 输出结构总览

```
# [提示词标题]

## 📝 完整提示词

[代码块包裹的完整提示词，可直接复制使用]

---

## 📖 使用说明

[如何使用这个提示词的分步说明]

---

## ⚙️ 参数说明

[表格列出所有可自定义参数及调整建议]

---

## 🔄 变体建议

[2-3 个不同场景下的调整方向]
```

---

## 第一部分：完整提示词

**要求**：
- 用代码块（\`\`\`）包裹
- 结构化、可直接复制到 AI 对话窗使用
- 包含所选场景的全部核心要素
- 若有 Few-Shot 示例，附在提示词中
- 使用 `{{占位符}}` 标记用户需要替换的变量

**文字提示词示例**：

````markdown
## 📝 完整提示词

```markdown
# C — Context（上下文）
- 背景：{{任务背景，为什么需要做}}
- 目标受众：{{谁来读}}
- 使用场景：{{在什么情况下用，什么媒介}}
- 品牌/语调：{{风格方向}}

# R — Role（角色）
你是一名专业的{{角色}}，擅长{{领域}}。

# I — Instruction（指令）
{{一句话任务描述}}。输入：{{用户会提供什么}}，输出：{{期望产出什么}}。

# S — Scenario（场景约束）
1. 长度：{{字数/段落要求}}
2. 风格：{{正式/轻松/专业/幽默等}}
3. 必须包含：{{关键信息点}}
4. 禁止出现：{{不需要的内容}}

# P — Prompt（整合与示例）
示例：
输入：{{典型输入}}
输出：{{理想输出}}

---

现在请处理：{{用户实际输入}}

# E — Evaluation（评估标准）
- {{标准 1}}
- {{标准 2}}
```
````

**文生图提示词示例**：

````markdown
## 📝 完整提示词

```markdown
# 主体
{{主体描述}}

# 环境
{{环境描述：地点、时间、天气}}

# 构图
{{景别、角度、焦点}}

# 光线与氛围
{{光源方向、色温、情绪基调}}

# 风格与画质
{{艺术风格、技术质量词}}

# 平台参数
{{MJ: --ar 16:9 --v {版本} / SD: 附 negative prompt / DALL-E: 无需额外参数}}
```
````

---

## 第二部分：使用说明

**要求**：
- 清楚说明使用步骤
- 列出预期效果
- 标注注意事项

**模板**：

```markdown
## 📖 使用说明

### 使用步骤
1. **准备输入**：[说明需要准备什么信息]
2. **替换变量**：将 `{{变量名}}` 替换为实际内容
3. **发送请求**：将完整提示词发送给 AI 模型
4. **调整优化**：根据输出结果，微调提示词参数

### 预期效果
- ✅ [效果 1]
- ✅ [效果 2]
- ✅ [效果 3]

### 注意事项
- ⚠️ [使用中需要注意的问题 1]
- ⚠️ [使用中需要注意的问题 2]
```

---

## 第三部分：参数说明

**要求**：
- 用表格列出所有可自定义的参数
- 说明每个参数的作用和可选值
- 给出不同情况的调整建议

**模板**：

```markdown
## ⚙️ 参数说明

| 参数 | 位置 | 说明 | 可选值/示例 |
|------|------|------|-------------|
| {{参数1}} | 提示词中第X部分 | {{参数作用}} | {{可选值}} |
| {{参数2}} | 提示词中第Y部分 | {{参数作用}} | {{可选值}} |

### 调整建议
- **{{参数1}}**：[如何根据场景调整]
- **{{参数2}}**：[如何根据场景调整]
```

---

## 第四部分：变体建议

**要求**：
- 提供 2-3 个不同场景的调整方案
- 每个变体说明适用场景和具体修改方法
- 给出修改后的关键部分示例

**模板**：

```markdown
## 🔄 变体建议

### 变体 1：{{场景名称}}
**适用场景**：{{什么时候用}}

**修改方法**：
- {{修改点 1}}：{{具体怎么改}}
- {{修改点 2}}：{{具体怎么改}}

**修改后关键部分**：
```markdown
{{修改后的关键段落}}
```

---

### 变体 2：{{场景名称}}
**适用场景**：{{什么时候用}}

**修改方法**：
- {{修改点 1}}：{{具体怎么改}}
```

---

## 质量检查清单

生成完毕后自检：

- [ ] 4 个部分完整无缺
- [ ] 完整提示词可直接复制使用，`{{占位符}}` 标记清晰
- [ ] 使用说明包含步骤、预期效果、注意事项
- [ ] 参数说明用表格呈现，覆盖所有可自定义项
- [ ] 变体建议不少于 2 个，且覆盖不同使用场景
- [ ] Markdown 格式正确（代码块闭合、表格对齐、标题层级合理）
