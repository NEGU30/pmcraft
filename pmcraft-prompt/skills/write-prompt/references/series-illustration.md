# 系列插图风格一致性指南

当生成一组系列插图（绘本、漫画、海报组图、IP 角色组图等）时，核心挑战是**保持风格一致**。本文档定义了方法论、各平台专项技法和实战模板。

---

## 一、核心原理

**把风格锁死，把内容放开。** 将提示词拆为两层：

| 层级 | 作用 | 策略 |
|------|------|------|
| **变化层** | 每张图不同的内容 | 主体、动作、场景 → 每张替换 |
| **锁定层** | 全部共用的风格要素 | 风格、色调、光线、画质、笔触特征 → 每张原样粘贴 |

---

## 二、通用技法

### 1. 风格锚点法

先花时间磨一张"风格定调图"，满意后作为后续所有图的风格参考。

**步骤**：
1. 生成第一张 → 反复调整直到风格完美
2. 记录该图的完整锁定层 + 外观锚点
3. 后续每张图只替换变化层，锁定层一字不动
4. 可选：将定调图作为参考图上传给后续 prompt

### 2. 统一外观锚点法

主角的外观特征必须**精确到可验证**。不是"一只猫"，而是：

```
外观锚点示例：
- 橘猫，左耳有三角形缺口，翠绿色眼睛，尾巴尖有一撮白毛
- 穿深蓝色连帽卫衣（帽子永远不戴），左手腕戴一条红绳
```

**规则**：至少写 3 个显眼且不会和其他角色混淆的特征。这 3 个特征写入每一张图的 prompt。

### 3. 统一提示词骨架法

先写好骨架模板，每张图只替换 `{{变化层}}` 部分：

```
{{变化层：主体 + 动作 + 场景，每张不同}}

{{锁定层：以下段落每张图原样粘贴，一字不改}}
{画风描述}，{色调方案}，{光线设定}，{笔触/质感}，
{构图偏好}，{画质参数}，{风格参考系}
```

### 4. 色板锁定法

写死一组颜色词，每张图复用：

```
统一色调：
- 主色：暖杏色系（#F5E6D3 方向）
- 辅色：鼠尾草绿、奶油白
- 点缀色：深棕（仅用于轮廓线和阴影）
- 光线：下午 4 点金色侧光，色温 4500K
- 饱和度：整体偏低，莫兰迪调子
```

## 三、各平台专项技法

> 各平台模型/参数说明截至 2026-07 校验（模型版本与参数随官方迭代变化，生成前以官方最新文档为准）。

### Midjourney

| 技法 | 写法 | 说明 |
|------|------|------|
| 锁种子 | `--seed 12345` | 固定随机种子，构图和色调更稳定 |
| 风格参考 | `--sref {定调图URL}` | 让后续图模仿定调图的风格 |
| 角色参考 | `--cref {角色图URL}` | 锁角色外貌，MJ 会自动保持脸部一致 |
| 风格权重 | `--sw 100` | 0-1000，越高风格参考越重。系列插图建议 `--sw 100` |
| 组合示例 | `--sref {URL1} --cref {URL2} --seed 12345 --sw 100` | 三锁齐下 |

### Stable Diffusion (SD/SDXL)

| 技法 | 操作 | 说明 |
|------|------|------|
| 锁种子 | `Seed: 12345` | 固定即可，每次微调 +1 |
| 同一模型 | 固定 Checkpoint + LoRA | 换模型等于换画风，系列固定用同一个 |
| IP-Adapter | 用参考图驱动风格和角色 | 比纯 prompt 描述更稳定 |
| ControlNet | 固定构图/姿势 | 适合需要统一版式（如绘本固定景别） |
| 提示词模板 | 锁定层放前面（SD 对 prompt 前半段注意力更高） | `{锁定层}, {变化层}` |

### DALL-E 3

- 通过 ChatGPT 对话式操作：上传风格参考图，告诉它"以后所有图都用这种风格"
- 后续每张只需描述新内容，DALL-E 通过对话上下文保持风格
- **注意**：DALL-E 3 内容过滤严格，角色一致性不如 MJ/SD 稳定

### ChatGPT 生图（GPT-4o 原生）

- **天然最强方案**：多轮对话天然保持上下文
- 第一轮："生成一张儿童绘本风格的插画：{定调图描述}"
- 之后每轮："同样的画风和色调，但画{新内容}"
- 如果风格飘了 → "回到第一张的风格，重新画{新内容}"
- 可以上传定调图："参考这张图的风格和色调"

### Nano Banana Pro

- 上传定调图作为参考（最多支持 14 张参考图）
- 每张 prompt 写："保持与参考图相同的风格、色调和画质。{变化层}"
- 角色一致性天然较强——Gemini 对"同一个角色"的连续性理解较好
- 文字渲染是加分项，系列绘本配文可直接在生图时生成

### 即梦

- 垫图模式："参考图片风格，主体不变，新场景：{描述}"
- 即梦 4.0 的**角色一致性功能**是核心卖点——跨场景保持主体外观不变
- 中文文字渲染突出，系列海报/绘本配文可直接生成
- 提示词写法：第一张定调 → 保存 seed → 后续用相同公式+seed

### 可灵

- 固定 prompt 后半段风格词，只换前半段内容
- 锁种子（如果平台支持 seed 参数）
- 英文 prompt 更稳定，风格词用英文精准术语
- **重要提醒**：不要写"高清""4K"等无效词，分辨率通过面板设置
- 中式风格词敏感度高——"宋代美学""水墨晕染"比英文翻译更稳定

## 四、实战模板

### 模板 1：绘本插图（适合 MJ / SD / 可灵）

```
# 系列：《{绘本标题}》
# 总张数：{N} 张
# 主角外观锚点：
- {特征 1}
- {特征 2}
- {特征 3}

# 锁定风格层（每张图原样粘贴，一字不改）：
{画风描述：如"儿童水彩绘本风格，类似吉卜力早期手绘质感"}
{色调方案：如"柔和暖杏色调，饱和度中等偏低"}
{光线设定：如"恒定下午金色侧光，色温 4500K"}
{笔触/质感：如"铅笔线稿打底+水彩上色，边缘轻微晕染"}
{构图偏好：如"中景为主，三分法构图，每张保留底部 15% 留白用于文字"}
{画质参数：如"2K，轻微胶片颗粒感"}

---

## 图 1：{标题}
{变化层：主体 + 动作 + 场景描述}

{锁定风格层（原样粘贴）}

---

## 图 2：{标题}
{变化层：主体 + 动作 + 场景描述}

{锁定风格层（原样粘贴）}
```

### 模板 2：IP 角色组图（适合 ChatGPT 生图 / 即梦）

```
# 角色名：{IP 名称}
# 外观三要素：
1. {最显眼特征，如"穿明黄色连帽衫，帽子上有猫耳"}
2. {第二特征，如"右手永远戴一只露指红手套"}
3. {第三特征，如"背一个过大的帆布包，包上别满徽章"}

# 固定风格层：
3D 渲染，类似皮克斯动画电影质感，暖色调，柔光箱正面光，
角色永远居中构图，背景简洁不过度抢眼，2K

# 使用方式：
- 后续每张图只描述角色在什么场景、做什么动作
- 外观三要素和风格层每个 prompt 都贴上，一字不改
- 如果角色脸变了 → 拿第一张图做参考图喂给平台
```

### 模板 3：品牌海报系列（适合 Nano Banana / 即梦）

```
# 系列主题：{主题名}
# 统一视觉规范：
- 品牌色：#1A1A2E（深蓝黑）+ #E94560（霓虹红）+ #FFFFFF（白）
- 字体风格：无衬线粗体，主标题白色，副标题霓虹红
- 构图：16:9 横版，产品居中偏右，左侧留白放文字
- 风格：赛博朋克×极简，霓虹光效，深色背景
- 画质：超写实，电影级打光

# 使用方式：
每张海报在"统一视觉规范"基础上只改：
1. 产品（居中替换）
2. 主标题文字
3. 背景霓虹配色微调（同色系）
```

## 五、常见翻车与排障

| 问题 | 表现 | 根因 | 解法 |
|------|------|------|------|
| **角色每张长得不一样** | 同一主角，图 1 和图 3 像两个人 | 外观锚点太模糊（"一只可爱的猫"） | 锁定 3 个显眼特征写入每张 prompt（"左耳缺口、绿眼、尾尖白毛"） |
| **色调逐张漂移** | 图 1 暖黄，图 3 偏冷蓝 | 光线词每张不同，或没写死色温 | 锁定层写死时间和光源（"恒定黄昏金色侧光，色温 4500K"），一字不改 |
| **画风越来越偏** | 图 1 手绘风，图 5 变 3D 写实 | 风格词太虚（"温暖的画风"） | 用具体参考系（"吉卜力《龙猫》美术风格"）+ 上传定调图做风格参考 |
| **换了平台全丢** | 跨平台后风格完全不统一 | 每个平台对同一描述的实现不同 | **同一系列用同一平台**。如果必须跨平台，每平台各跑一张定调图而非共用 |
| **锁了 seed 构图还是变** | 改了 prompt 内容 seed 参考价值下降 | seed 锁定的是随机数，prompt 改动越大效果越不可控 | 变化层只改主语和宾语，句式结构保持完全一致 |
| **风格参考图权重太高** | 后续图连构图都死板复制定调图 | `--sw` 或参考图权重拉满 | 降低风格权重（如 MJ `--sw 50`），给变化层留创作空间 |

## 六、快速检查清单

生成系列插图前，确认以下事项：

- [ ] 主角外观锚点已定义（至少 3 个显眼特征）
- [ ] 锁定风格层已写好（画风+色调+光线+质感+画质，一字不改的段落）
- [ ] 已跑一张定调图并确认满意
- [ ] 目标平台已选定（同一系列不跨平台）
- [ ] 如果平台支持 seed/sref/cref → 已记录定调图的这些参数
- [ ] 变化层只替换"谁在哪做什么"，句式结构保持一致
